# علی رضازاده بگلر — سایت خدمات نقشه‌برداری

وب‌سایت استاتیک فارسی، راست‌چین و واکنش‌گرا برای معرفی خدمات نقشه‌برداری و داده‌های مکانی. طراحی با الهام کلی از وب‌سایت‌های شرکتی مهندسی مانند REGA انجام شده، اما ساختار و محتوای اختصاصی دارد.

## فایل‌ها
- \`index.html\`: صفحه اصلی و تمام CSS/JavaScript لازم. بدون نیاز به build یا فریم‌ورک.

## انتشار با Cloudflare Pages و دامنه alirezazade.ir
1. وارد داشبورد Cloudflare شوید و از **Workers & Pages → Create → Pages → Connect to Git** مخزن \`alirezazadehbeglar-bit/site\` را متصل کنید.
2. شاخه انتشار را \`main\` انتخاب کنید.
3. چون سایت HTML استاتیک است، فرمان build را خالی بگذارید و **Build output directory** را \`/\` یا در صورت نپذیرفتن آن \`.\` وارد کنید. اگر رابط تنظیمات ریشه را نپذیرفت، از Direct Upload با پوشه‌ای که \`index.html\` داخل آن است استفاده کنید.
4. پس از اولین انتشار، در تنظیمات پروژه به **Custom domains → Set up a custom domain** بروید و \`alirezade.ir\` را اضافه کنید. همچنین \`www.alirezade.ir\` را در صورت نیاز جداگانه اضافه و به دامنه اصلی هدایت کنید.
5. اگر DNS دامنه در Cloudflare مدیریت می‌شود، مراحل DNS پیشنهادی داشبورد را تأیید کنید. گواهی HTTPS پس از تکمیل تنظیمات دامنه فعال می‌شود.
